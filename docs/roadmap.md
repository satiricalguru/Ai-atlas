# Roadmap

## Implemented foundation
Landing, 3D/fallback, demo, authenticated route protection, Supabase auth flows, onboarding, overview, application management, imports, explorer, computed insights/fingerprint/network, settings, exports, deletion, migrations and server adapter/workflow code.

## Deployment-dependent acceptance
Configure Supabase, apply migration, enable email/GitHub and redirect allowlist, set encryption and service keys; configure Inngest. Verify email delivery, recovery, two-user RLS isolation and a real permitted admin connector. These cannot be certified without external accounts/credentials.

## Next increments
Provider-specific Cursor/Copilot report parsers after permissioned real fixtures; Gemini Cloud IAM reporting; verify Perplexity Analytics schema. Add account-mapped multi-source reconciliation so the same underlying usage is never double-counted. Durable large-file import pipeline, retention controls, schema migrations and generated Supabase types from the actual deployed project. Subscription invoice ingestion with user-confirmed billing periods. Accessibility audit and real-device WebGL profiling. Production alerts, backup/restore drill and penetration testing before commercial launch.
