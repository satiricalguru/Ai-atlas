# Integration matrix · verified 30 October 2026

An API credential is not a consumer chat-history permission. No cookies, hidden endpoints or scraping are used. Live credentials were not supplied in this workspace; no live account is claimed to be verified.

| Product | Official source / permissions | Data and limitations | Implementation |
|---|---|---|---|

Organization admin authority required; respect 429/Retry-After and pagination. | Server adapter, verified connection check, encrypted key and durable sync workflow; not live verified without credentials. |

## Reporting semantics
Event ledger: individually recorded imported interactions. API usage snapshots: aggregate requests and tokens, shown separately and never expanded into fake conversation events. Subscription spending is unavailable unless provided as reliable metadata. No inferred working duration. No provider connected badge until server verification succeeds. Imports are shown as imports, not connections.

## Rate limits / approval
Limits depend on plan, organization and endpoint; no single universal rate is asserted. Background jobs bound pages, honor retry headers, persist cursors and use Inngest retries. OAuth login to Atlas (configured GitHub in Supabase) does not authorize reading Copilot analytics. Only OpenAI and Anthropic API organization adapters are implemented; all other live connectors are explicitly unavailable in the UI.
